# 도서관 자율주행 로봇 키오스크

## 📖 프로젝트 소개

이 프로젝트는 도서관 내 자율주행 로봇에 탑재되는 키오스크용 안드로이드 애플리케이션입니다. 사용자가 원하는 책이나 장소를 쉽게 찾아갈 수 있도록 **실시간 길안내 기능**을 핵심으로 제공하며, 추가적인 편의 기능들을 포함하고 있습니다.

## ✨ 주요 기능

- **실시간 길안내**: 사용자의 목적지까지 최적의 경로를 계산하여 화면에 표시합니다.
- **위치 추정**: 실시간으로 수집된 Wi-Fi 신호 세기(RSSI)를 분석하여 로봇의 현재 위치를 맵에 표시합니다.
- **도서 검색**: 도서관이 소장한 도서를 검색하고 위치를 확인할 수 있습니다.
- **MBTI 기반 도서 추천**: 간단한 MBTI 검사를 통해 사용자의 성향에 맞는 책을 추천해줍니다.
- **공지사항**: 도서관의 새로운 소식이나 공지사항을 확인할 수 있습니다.

## 🤖 핵심 기술

### 1. 위치 추정 (Localization)

- **Wi-Fi 신호 세기 (RSSI)**: 별도의 GPS 장치 없이, 도서관 내에 설치된 Wi-Fi AP들의 신호 세기를 실시간으로 측정합니다.
- 수집된 신호 데이터를 기반으로 로봇의 현재 위치를 추정하여 지도 위에 표시함으로써, 사용자가 자신의 위치를 직관적으로 파악할 수 있도록 돕습니다.

### 2. 경로 탐색 (Pathfinding)

- **최단 경로 알고리즘**: 사용자가 목적지를 선택하면, 현재 위치로부터 가장 효율적인 경로를 계산합니다. (예: 다익스트라, A* 알고리즘 등)
- 계산된 경로는 지도 위에 시각적으로 표시되어 사용자가 따라가기 쉽게 안내합니다.
  

## 🛠️ 기술 스택

- **언어**: Java
- **플랫폼**: Android
- **개발 도구**: Android Studio
- **빌드 시스템**: Gradle

## 🚀 빌드 및 실행

1.  `git clone`으로 프로젝트를 다운로드합니다.
2.  Android Studio에서 프로젝트를 엽니다.
3.  Gradle 빌드가 완료될 때까지 기다립니다.
4.  에뮬레이터 또는 실제 안드로이드 기기에서 앱을 실행합니다.
